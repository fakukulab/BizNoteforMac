BizNote for Mac 개인정보 처리방침

시행일: 2026년 9월 2일

개요

BizNote for Mac은 업무 노트, 회의록, 전시회 기록, 명함 정보를 관리하는 macOS용 생산성 앱입니다. 앱은 별도의 계정 가입이나 로그인을 요구하지 않습니다.

앱에 저장되는 데이터

BizNote는 사용자가 입력하거나 선택한 노트, 명함 정보, 명함 이미지, 첨부파일, 행사 정보, 회의 정보, 업무 항목, 태그, 사용자 설정, 위치 텍스트를 저장할 수 있습니다.

이 데이터는 사용자의 기기에 저장됩니다. 사용자가 iCloud 동기화를 켠 경우 Apple의 CloudKit 서비스를 통해 사용자의 개인 iCloud 계정에 동기화될 수 있습니다.

데이터 수집

개발자는 BizNote 사용자 데이터를 수집하기 위한 별도 서버를 운영하지 않습니다.

개발자는 사용자의 노트, 명함 정보, 이미지, 첨부파일, iCloud 데이터에 접근할 수 없습니다.

추적 및 광고

BizNote는 앱과 웹사이트를 넘나드는 사용자 추적을 하지 않습니다.

BizNote는 타사 광고 SDK, 분석 SDK, 추적 SDK를 포함하지 않습니다.

권한 사용

카메라 권한은 명함을 촬영하고 텍스트를 인식하기 위해 사용됩니다.

연락처 권한은 연락처 정보 가져오기, 중복 확인, 검토한 명함 정보를 연락처 앱에 저장하기 위해 사용됩니다.

위치 권한은 사용자가 회의 또는 행사 장소를 찾거나 현재 위치를 기록에 입력하는 기능에 사용됩니다.

캘린더와 미리알림 권한은 사용자가 선택한 경우 행사와 업무 항목을 Apple 캘린더 또는 미리알림 앱에 추가하기 위해 사용됩니다.

사용자 선택 파일 접근 권한은 사용자가 선택한 위치로 PDF 또는 스프레드시트 파일을 내보내기 위해 사용됩니다.

데이터 삭제

사용자는 앱 안에서 노트, 명함, 첨부파일, 행사 정보, 사용자 템플릿을 삭제할 수 있습니다.

앱을 삭제하면 기기에 저장된 로컬 앱 데이터가 제거됩니다. iCloud 동기화를 사용한 경우 동기화된 데이터는 Apple의 iCloud 데이터 처리 방식에 따라 사용자의 iCloud 계정에 남아 있을 수 있습니다.
